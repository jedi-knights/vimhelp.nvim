2. Setup                                             *vimhelp-setup*

setup() is optional — the plugin loads its `plugin/` entry on startup
and defers the rest to first `require()`. Call setup only when you
need to override defaults or inject dependencies.
>lua
    require("vimhelp").setup({
      -- your config here
    })
<
The second argument accepts injected dependencies so tests can swap
production collaborators for fakes:
>lua
    require("vimhelp").setup({}, { notifier = fake })
<

3. API                                                 *vimhelp-api*

Submodules:

- `require("vimhelp").config`   — defaults and merge helper
- `require("vimhelp").detector` — should_load() gate
- `require("vimhelp").health`   — |:checkhealth| entry point

4. Health                                           *vimhelp-health*

Run `:checkhealth vimhelp` to verify the plugin loaded and
