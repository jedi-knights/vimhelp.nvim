1. Introduction                                                *vimhelp-intro*

vimhelp.nvim wires the |vimhelp-index| CLI into Neovim: full-text search
over |:help| that finds the doc you need without knowing the exact tag.

The plugin is a thin shim — it invokes the vimhelp-index binary as a
subprocess, parses the JSON response, and renders ranked hits. The
heavy lifting (tantivy index, BM25 scoring, snippet highlighting) lives
in the CLI.

==============================================================================
2. Requirements                                         *vimhelp-requirements*

- Neovim 0.10+.
- The `vimhelp-index` binary on `$PATH`, or a `binary_path` set via
  |vimhelp-setup|. Install from:
  https://github.com/jedi-knights/vimhelp-index/releases
- An index directory built by `vimhelp-index build`. Default location:
  `stdpath("cache") .. "/vimhelp-index"`.

==============================================================================
3. Setup                                                       *vimhelp-setup*

setup() is optional — defaults ship in config.lua and the |:VimHelpSearch|
command works with no configuration when vimhelp-index is on PATH and
the default index directory exists. Call setup only to override defaults.
>lua
    require("vimhelp").setup({
      binary_path = "/opt/homebrew/bin/vimhelp-index",  -- override PATH lookup
      index_dir   = vim.fn.stdpath("data") .. "/help-index",
      limit       = 10,
    })
<

==============================================================================
4. Commands                                                 *vimhelp-commands*

------------------------------------------------------------------------------
4.1. :VimHelpSearch                                         *:VimHelpSearch*

>
    :VimHelpSearch {query}
<
Search the vimhelp index for {query} and print ranked hits to |:messages|.
Multi-word queries work: `:VimHelpSearch floating window` is a single
query, not two.

Rejects an empty query with an actionable message. Errors clearly if the
binary is missing (points at the install URL) or the index directory
doesn't exist (points at the build command).

Example output: >
    1. nvim_open_win  (score 3.42)
       $VIMRUNTIME/doc/api.txt:1287  — 3.2. Window functions
       Opens a new floating window. Windows attach to a buffer …

    2. wincfg-title  (score 1.85)
       ...
<

==============================================================================
5. Configuration                                             *vimhelp-config*

Defaults (see `lua/vimhelp/config.lua`):
>
    {
      binary_path = nil,     -- nil probes $PATH for "vimhelp-index"
      index_dir   = stdpath("cache") .. "/vimhelp-index",
      limit       = 20,      -- 0 means the CLI's default cap
    }
<

==============================================================================
6. API                                                         *vimhelp-api*

Submodules (`require("vimhelp.<name>")`):

- `config`   — defaults and merge helper
- `binary`   — subprocess invocation (`resolve`, `search`). Injectable
               `runner` for tests.
- `search`   — pure `parse` + `render` for the CLI's JSON envelope.
- `health`   — |:checkhealth| entry point.

Facade (`require("vimhelp")`):

- `setup(opts?, deps?)` — merge opts over defaults; optional.
- `search(query, deps?)` — resolve binary + run subprocess + parse + print.
                           Returns the raw parsed result so callers can
                           pipe it further (a future picker slice will).

==============================================================================
7. Health                                                    *vimhelp-health*

Run `:checkhealth vimhelp` to verify:

- The plugin loaded and the detector permits execution.
- `vimhelp-index` is discoverable on PATH (or at the configured
  `binary_path`).
- The configured `index_dir` exists.

Both binary-not-found and index-not-found surface as actionable health
reports pointing at the install URL and the build command respectively.
